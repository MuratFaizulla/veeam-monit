# docs/

Справочные материалы. Ничего отсюда не попадает в образ и не читается кодом.

- **`veeam-openapi.json`** — спецификация REST API **Veeam Backup & Replication**,
  то есть чужого API, к которому мы ходим. Не путать с документацией этого
  сервиса: она не лежит файлом, а собирается из кода и отдаётся живым сервисом
  по `/api/docs`. Раньше файл лежал в корне под именем `veeam-swagger.json`, и
  рядом с собственным swagger это имя стало двусмысленным.
